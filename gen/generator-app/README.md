# YOUNGDO Studio

EULSUKDO와 ORYUKDO Gen2를 사용하는 웹 생성기입니다. 을숙도의 두 FIFO 방식 LSQ는 선택형이며 기본 OFF입니다. 오륙도는 복구·예외·인터럽트·Store 전달과 순차 외부 공개를 포함하며 정적/외부 분기예측기를 선택할 수 있습니다. 최신 연결 계약과 검증 범위는 [사용설명서](USER_GUIDE.md)를 참고하세요.

```sh
npm ci
npm run dev
npm run lint
npm run build
npm run verify:rtl
```
